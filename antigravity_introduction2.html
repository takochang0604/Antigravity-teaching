第一部分：Antigravity 基本介紹

1.1 🤖 什麼是 Antigravity？

IDE（整合開發環境）就是一個把寫程式、除錯、執行整合在一起的開發工具，是一款能讓你用自然語言快速打造工具與自動化流程的 AI 開發平台。

能力說明
🖥️ 讀寫檔案直接在你的電腦上建立、修改、刪除檔案
🌐 瀏覽網頁開啟瀏覽器、點擊按鈕、填寫表單、擷取網頁資訊
⚙️ 撰寫程式自動產生完整的程式碼與應用程式
🔍 搜尋資訊即時搜尋網路、搜尋檔案內容
🎨 生成圖片根據文字描述產生圖片素材

1.5 🚀 實際操作教學

情境一：製作個人記帳工具

📌 你只需要說：
「幫我做一個記帳工具，可以輸入日期、金額、分類，自動算出每月花費統計」

Antigravity 會自動：

  1. 規劃網頁表單架構
  2. 建立 HTML / CSS / JavaScript 檔案
  3. 設計美觀的介面（深色主題、圖表統計）
  4. 加入分類篩選與月報功能
  5. 啟動本地伺服器讓你即時預覽（請用 localhost 幫我開啟這個 html）

情境二：製作 AI 風格證件照生成器

📌 你只需要說：
「幫我做一個證件照生成器，上傳照片後可以選擇台系、日系、韓系三種風格，用 AI 自動套用對應的濾鏡與美感」

Antigravity 會自動：

  1. 建立照片上傳介面，支援拖曳上傳
  2. 提供三種風格選擇：
    • 🇹🇼 台系：自然清爽、色調忠實、適合正式場合
    • 🇯🇵 日系：高曝光、柔焦感、淡色調、膠卷質感
    • 🇰🇷 韓系：白皙透亮、柔光美顏、寫真館氛圍感
  3. 套用對應濾鏡（亮度、對比、色溫、柔化）即時預覽
  4. 三種風格並排展示，一鍵下載

第二部分：Skills 系統介紹

2.1 📚 什麼是 Skills？

⚠️ 重點： Skills（技能） 是 Antigravity 最強大的功能之一——它讓你可以把自訂的專業知識教給 AI。

想像你有一位非常聰明的新助理（Antigravity），但他剛入職，還不了解你公司的：

  • 內部規範
  • 常用工具的使用方式
  • 專案的特殊需求

Skills 就是你給這位助理的「工作手冊」——寫好之後，他就能按照你的方式做事。

2.2 🏆 Skills 的核心價值

把 2.1 那三件「助理不懂的事」，分別寫成工作手冊——他就全都懂了。
graph TD A["📥 你的需求（一句話）"] --> B["📖 Skill 常用工具手冊"] A --> C["📖 Skill 內部規範手冊"] A --> D["📖 Skill 專案知識手冊"] B --> E["✅ 按公司方式完成任務 不需重新交代"] C --> E D --> E
優勢用「新助理」比喻來說
♻️ 可重複使用工作手冊寫一次，助理每次都照做，不用重複交代
👥 可分享整個團隊的助理都拿同一本手冊，標準一致
✏️ 可迭代說「把第三條規則改成這樣」，助理馬上更新，立即生效
📐 標準化不管換哪位助理，產出品質都一樣穩定

2.3 📝 如何建立 MD 檔？

Skills 系統的所有設定檔都是 .md（Markdown）檔案——一種純文字格式，不需要任何特殊軟體就能編輯。

方法一：手動建立（最基本）

步驟操作
①在資料夾中按右鍵 → 新增 → 文字文件
②將檔名改為你要的名稱，副檔名從 .txt 改成 .md（例如 rules.md、SKILL.md）
③用記事本、VS Code 或任何文字編輯器打開，直接寫入內容
⚠️ 注意： 如果看不到副檔名，請先到檔案總管 → 檢視 → 顯示 → 副檔名，打勾開啟。

方法二：請 Antigravity 幫你建（推薦 ⭐）

你完全不需要自己動手建檔——直接跟 Antigravity 說：

📌 你只需要說：
「幫我建立一個 rules.md，規定所有回覆用繁體中文、語氣專業友善」

「幫我建立一個 SKILL.md，功能是搜尋今日 AI 新聞並選出 2 篇最有話題性的」

Antigravity 會自動在正確的路徑建立檔案、寫好格式與內容，你只需要確認即可。

💡 結論： MD 檔就是純文字檔，換個副檔名而已。但最簡單的方式是直接請 Antigravity 幫你建，連格式都不用記。

2.4 📄 三大機制的格式與寫法

📌 Rules — 全域規則

  • 不管你現在要做什麼事，都先遵守這些基本規定
# 全域行為規則

- 所有回覆請使用繁體中文
- 回覆風格應專業且友善，避免過於正式
- 執行任何操作前，先確認使用者需求
- 涉及刪除或覆蓋操作時，必須先徵詢確認

⚡ Workflows — 任務流程

  • 這件事要怎麼一步一步做
---
description (描述): AI 新聞選題、改寫、封面圖產出的完整發布流程
---

1. 搜尋今日 AI 新聞，選出 2 篇最具話題性的文章
2. 將選定文章改寫為可直接發布的原創成稿（含 SEO 欄位）
3. 為每篇文章產出 2 組封面圖方向與提示詞，並生成封面圖
4. 詢問是否需要同步存入文章資料庫
💬 觸發方式：對 Antigravity 說 /publish-news 即可啟動完整新聞產線

# 詳細指令

## 步驟一：...
具體的操作說明
💡 Skills 的觸發是自動的 — 你不需要指定用哪個 Skill，AI 會根據需求描述自動比對並取用。同一需求可同時觸發多個 Skills。

修改 Skill 也只要一句話 — 對 Antigravity 說「幫我更新這個 Skill，加上 XXX 規則」，它會直接回寫並儲存對應的 SKILL.md，即時生效。

Skill ① — ai-news-selector（選題）

---
name: ai-news-selector
description: 當使用者要爬取今日新聞、挑選最吸睛的幾篇新聞時啟用。
             此 Skill 專門負責搜尋、篩選與選題，不負責改寫或圖片生成。
---

## 目標
從固定新聞來源中抓取當日新聞，選出最適合後續改寫的 2 篇文章。

## 核心規則
1. 只處理「當日發布」的文章
2. 排除非正文頁、低價值頁面
3. 依吸睛程度、話題性、資訊完整度綜合排序
4. 輸出：原始標題、來源、連結、入選原因、摘要、建議關鍵字

Skill ② — ai-news-rewriter-seo（改寫成稿）

---
name: ai-news-rewriter-seo
description: 當使用者已提供完整新聞內容，並要求改寫成可直接發布的成稿時啟用。
             不負責搜尋新聞或挑選題材。
---

## 目標
將完整中文新聞轉為可直接發布的原創成稿，含 SEO 欄位。

## 核心規則
1. 保留可驗證事實，完成原創重述
2. 不可逐句照抄、不可有 AI 口吻
3. 主關鍵字需出現在標題、前 150 字、正文中
4. 輸出：H1 標題、正文、參考資料、關鍵詞、SEO 網址/標題/敘述

Skill ③ — blog-cover-brief-generator（封面圖）

---
name: blog-cover-brief-generator
description: 當使用者已提供文章標題與內文，並要求產出封面圖方向時啟用。
             不負責搜尋新聞或改寫全文。
---

## 目標
為每篇文章產出 2 組 16:9 封面圖方向與圖片生成提示詞。

## 核心規則
1. 每篇文章 2 組方向，需有明顯差異
2. 提示詞開頭必須包含 wide horizontal composition, 16:9 aspect ratio
3. 產圖後需裁切為 16:9 並壓縮為 JPEG
4. 輸出：方向名稱、視覺主軸、構圖描述、提示詞

📊 有 Skills vs 沒有 Skills

❌ 沒有 Skills✅ 有 Skills
選題標準每次都要交代篩選規則AI 自動套用 ai-news-selector
文章風格每次都要重新交代寫作規則AI 自動套用 ai-news-rewriter-seo
封面圖品質每次都要描述設計原則AI 自動套用 blog-cover-brief-generator
產出一致性隨對話不同而變化每次穩定一致
操作複雜度一大段指令一句話搞定

🎯 結語

Antigravity 的核心理念是讓每個人都成為「有 AI 幫手的超級工作者」。

你不需要學程式，只需要清楚表達你的需求，AI 就能幫你實現。
而 Skills 系統則讓你能把自己的專業知識「教」給 AI，實現真正的個人化工作助理。
